## 3. Build the next IPA and run it on the iPhone 13

The build is unchanged (`ios/tools/build_ios.sh`, GitHub workflow step 8). The app opens; the
diagnostics now write two files into the app's **Documents** directory, which
`UIFileSharingEnabled` + `LSSupportsOpeningDocumentsInPlace` already expose to the Files app:

* `phase02-run-journal.txt` — one line per step, written with a single `write(2)`, so it survives
  a termination that no handler could catch;
* `phase02-report-ahead.txt` — the report as it stood before the last risky step.

Press **Run Selected** once per suite (memory, jit, cpu, threads, signals, fs, ipc, loader) and
once with **all**. After each press, copy `phase02-run-journal.txt` out (Files app → Share) and
keep it with the report.

Reading it:

* the run finished → the journal ends with `JOURNAL_END` and the report exists;
* the process was terminated → the journal has no `JOURNAL_END`, and its **last** `event=` line
  is the step the process was inside:
  * `RUN_SELECTED_ENTER` / `HARNESS_INIT_ENTER` → it died before the harness was initialised;
  * `HARNESS_INIT_OK` / `REPORT_INITIALISED` → it died initialising the report;
  * `SUITE_DISPATCH_ENTER suite=X` → it died between the button and the suite;
  * `SUITE_ENTER suite=X` / `SUITE_FIRST_TEST_ENTER suite=X` → it died entering the first test
    of `X` — `SUITE_FIRST_TEST_ENTER` with no `SUITE_EXIT` is the run-03 signature;
  * `WRITE_AHEAD_OK` as the last line → the report on disk is complete up to that step.

Expected report content on the device, with the execution attempts deferred by policy:

`cpu`, `threads`, `signals`, `fs` and `ipc` are expected to be unaffected by that policy.

### 3.1 If a dedicated attempt is wanted (only deliberately)

To let the device actually try to enter written memory — the operation that terminated run 03,
with the journal and the write-ahead report already on disk:

* build with `-DPHASE02_IOS_ALLOW_EXECUTION_ATTEMPT=1`, or
* set `PHASE02_ALLOW_EXECUTION=1` in the scheme's environment.

The report then shows `attempt-opt-in=1` and the records are measurements again, not deferrals.
If the process still terminates, the journal says exactly where — that is the whole point of
section 3. Never set this in the run that is meant to collect the per-suite evidence.
